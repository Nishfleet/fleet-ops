### Conventions (process rules for this file itself)

- **Sunset convention:** every new standing rule carries a review-by date or an
  "absorbed into mechanism X" exit condition; the Weekly Fleet Review's quality
  ratchet reviews expiring rules.
- **Net-down convention:** a new standing rule requires naming which existing rule
  it merges into or replaces — net rule count trends DOWN.
