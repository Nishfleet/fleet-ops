## What changed

Part 3/4 of the self-maintenance budget (fleet-ops#3124). Adds the PR gate that makes fleet-ops PRs net-negative by default: a PR whose diff is net-positive in lines must carry a `net-positive-because:` line in the body, or the existing prove-one-run-check gate REJECTs it.

- `bin/prove-one-run-check`: new optional `--numstat FILE|-` flag. When provided, the gate computes the diff's net line change (added minus deleted, treating binary `-` as 0) and REJECTs a net-positive diff whose body lacks a `net-positive-because:` line. Backward compatible: omitting `--numstat` keeps the old machinery-only behaviour.
- `prompts/worker.md`: the prove-one-run-check invocation now passes `--numstat <(git diff --numstat origin/main...HEAD)`, and the prompt states the net-positive requirement.
- `tests/prove-one-run-check.test.sh`: new Phase F drills the gate — net-positive without marker rejects, with marker accepts, net-negative/neutral/binary-only accept, empty marker value rejects, and the combined machinery+net-positive cases.

net-positive-because: ships the required PR gate for fleet-ops (fleet-ops#3256); the added lines are the gate, its prompt wiring, and its drill.
