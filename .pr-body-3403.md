## Why

Blind-audit fleet-ops#3403: `fable-fleet-check.service` is a real hand-placed
user unit under `~/.config/systemd/user/` and was not on
`config/machinery-allowlist.json`, so `fleet-machinery-authorization-gate hunt`
flagged it as high-severity class-(c) drift (rank 81 in the 2026-09-04T22:09:39Z
report).

The unit is temporary — its own Description says "retire with
fleet-landing-watch", confirmed by the vault agent-drop
`2026-09-04T11-31-05Z-fleet-landing-watch-and-fable-fleet-check-units.md`. It is
class (a) hand-placed, the same shape as the `opus-heartbeat` watch family
already on the allowlist. `systemd/timer-manifest.json` already carries the
cadence entry (fleet-ops#3338). This PR adds the unit to the allowlist so the
hunt stops flagging it.

## Scope

- One allowlist entry in `config/machinery-allowlist.json`. No new systemd unit,
  no new MANIFEST line, no new bin, no new mechanism. An allowlist edit is paper,
  not machinery — `fleet-machinery-authorization-gate evaluate` only gates
  `systemd/**` / MANIFEST unit additions, and this PR adds neither.
