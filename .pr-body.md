## What changed and why

Part 2/2 of #3264 (child of #3127). Part 1/2 (#3708) owns the reviewer round itself; this part owns only what happens when no senior seat is usable.

When no entry of `senior_seats_in_order` is usable, the product worker still opens the PR but WITHOUT `gh pr merge --auto`, and the PR body carries the literal line `review: skipped, no capable seat` so the loose-ends canary surfaces it. Never skipped silently, never armed unreviewed.

- **lib/seat-lib.sh**: new `senior_seat_available()` — returns 0 when any entry of `senior_seats_in_order` is usable, 1 when the whole senior ladder is walled. Unlike `find_senior_seat`, it does NOT fall through to a non-senior capable seat: the reviewer must run on a senior seat or not at all.
- **bin/fleet-review-arm-check** (new): worker-facing arm gate. Exit 0 = a senior seat is usable (arm allowed); exit 1 = no senior seat usable (open the PR without the arm and mark the body `review: skipped, no capable seat`). Reuses lib/seat-lib.sh — no new mechanism, no new organ.
- **prompts/worker.md**: step 8 (arm) now instructs the worker to open the PR without auto-merge and add the body line when `bin/fleet-review-arm-check` exits 1.
- **lib/loose-ends.py + bin/fleet-loose-ends-canary**: a worker PR whose body carries `review: skipped, no capable seat` is classified `review-skipped-pr` and surfaced immediately (regardless of age) as its own LOUD class, so it is never skipped silently.
- **MANIFEST**: installs the new bin helper.
