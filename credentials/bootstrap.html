nishfleet-worker — one-click bootstrap

Click Create the GitHub App. The page posts the manifest to GitHub, which creates the app under the org you enter, then redirects back to a tiny local listener. No further clicks.

Only change this if you want the app under a different org than Nishfleet. The bootstrap listener writes credentials to ~/.config/fleet-worker/nishfleet-worker.env (mode 0600).

Generated from credentials/app-manifest.json. After the callback completes, the listener prints install command instructions for granting the app access to Nishfleet/0509 (and any other repos the workers need).
