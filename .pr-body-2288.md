## What changed and why

opencode/muse-spark-1.2-contributor-free reached 149 consecutive HTTP 500s
(failure_mode=transient_http) while being re-offered on a flat 30s cadence:
its ledger's usable_at was always observed_at + 30s, so once it elapsed the
seat was re-picked, failed again, and the count climbed forever — seat_dead
never flipped for the class (the issue's core ask: "transient_http backoff
must escalate with consecutive_failure_count and flip seat_dead (or a long
wall) past a threshold, same as empty_run backoff already does").

The write-side escalation for this class already shipped in the out-of-repo
seat-health extension (#1422 quarantine wall, #2145 seat_dead flip, #2327
terminal corpse reclassify — all closure-tested from this repo). The missing
half was **in this repo**: the bash fences (#1362/#1408) only cover
bash-written markers, and `seat_usable` had no fence for extension-written
transient_fault ledgers — so even a stale pre-fix ledger (count=149, flat
wall, seat_dead=false) was judged USABLE and kept being offered; only the
ledgers the extension re-parked to seat_dead=true/corpse (#2327) were safe.

This PR adds the read-side long-wall park:

- `seat_usable` now reads `consecutive_failure_count` from the ledger and,
  for `health_class=transient_fault` past `SEAT_FAILURE_CEILING` (60),
  holds the seat until `observed_at + SEAT_PARK_WALL_S` (24h), then
  fail-opens — one probe per park wall, not per flat window. Same fail-open
  contract as #1362: a healthy write resets the count to 0, so a recovered
  seat is never walled permanently. Precedence: the corpse seat_dead=true
  check (#2327) stays terminal-authoritative BEFORE this branch, and the
  branch sits BEFORE the stale-observed fail-open so a stale high-count
  transient ledger is parked, not resurrected. `pick_seat` inherits the
  fence because it consults `seat_usable` per candidate.
- `tests/seat-failure-ceiling.test.sh` gains read-side cases 6a-6f: the
  live c=149 replay, below-ceiling (no park), park-expired fail-open with
  both stale and still-fresh observed_at, inside-the-wall park, and the
  healthy-reset shape.
