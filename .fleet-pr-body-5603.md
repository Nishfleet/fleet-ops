## Summary

`lib/fleet-token-efficiency-check.py` `_looks_like_assembler()` classified any file containing "prompt"/"packet"/"pi --print"/etc. as a prompt assembler — including prose docs. `lib/standing-rules/canonical.md` (mentions `pi --print` 3x, carries `{{...}}` substitution tokens at line 48 of 110) was treated as a prompt template, so every PR touching it inherited an un-clearable REJECT (PR #5599 carry).

Fix per the issue's accept option (b): markdown outside `prompts/` is a prompt template only via `prompts/` path membership or literal template-substitution code (`tpl.replace`, `.replace('{{'`). The full marker set is unchanged for shell/python assembler sources. No canonical prose was rewritten.
