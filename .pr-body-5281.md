## seat-lib: prefer-class bucket copy `${X[@]:-}` phantom empty seat

Fixes #5281.

### What
With all prepaid seats benched and `.prefer-class=prepaid` set, `_pref_bucket=("${prepaid_seats[@]:-}")` expands to ONE empty-string element, so `${#_pref_bucket[@]}` is 1, `chosen=""`, and `model_class_of "" ""` hits `SEAT_PROVIDER_CLASS[""]` → `bad array subscript` at seat-lib.sh L932, plus the misleading `pick_seat: prefer-class=prepaid routing to <empty>` log line.

### Fix
Replaced every `("${X[@]:-}")` array expansion in `lib/seat-lib.sh` with the set-u-safe form `${X[@]+"${X[@]}"}` (11 sites: `_pick_expiring_floor_seat`, `_order_seats_by`, pick_seat vranked/yranked/prefer-class bucket/senior-review fallback). With an empty array the expansion now yields zero elements, so the prefer-class branch correctly falls through to the yield ladder with no stderr noise and no phantom routing log.

`pi-issue-run` and `bin/`, `lib/`, `libexec/` grepped for the same idiom: no other instances (`grep -rn '\[@\]:-}' lib/ libexec/ bin/` → no matches).
