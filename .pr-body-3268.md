## Why

Child of the waste-cut decision #3128 (report F7): fleet2, the forbidden second dispatcher, had ~199 inert open PRs inflating the console open-PR tile. Those PRs are already all closed in fleet2 (0 open), but a dead repo is only excluded from the console tile once it is ARCHIVED ("Console open-PR tile excludes archived repos"). This part 1/6 ships the reusable mechanism so a dead repo is retired the same way instead of by hand.

## Scope

- Add `bin/fleet-close-and-archive-repo`: enumerates every open PR in a target repo, closes each with one comment, then archives the repo with `gh repo archive`. Dry-run by default; `--apply` acts. Default target `Nishfleet/fleet2`.
- Add `tests/fleet-close-and-archive-repo.test.sh`: replay drill with a stubbed `gh`, locking dry-run-does-not-mutate, apply-closes-each-with-one-comment, archive-attempted, admin-gated-archive-surfaced-loudly-and-not-claimed, clean-repo, and missing-gh/empty-token exit 2.
- Register the tool in `MANIFEST`.

## Archive is Administration-gated (worker cannot archive)

Archiving a repo needs Administration on the repo. The `nishfleet-worker` App token deliberately has NO Administration (verified live: `gh repo archive Nishfleet/fleet2 --yes` -> `Resource not accessible by integration (archiveRepository)`), the same class as the branch-protection wall. So under the worker token `--apply` closes the open PRs (worker scope) and then reports the exact archive command for a scope that has Administration to run. It never claims the archive happened. This is a documented scope boundary, surfaced loudly.
